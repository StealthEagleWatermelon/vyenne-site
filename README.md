# vyenne-site

Static marketing and legal site for Vyenne, published by GitHub Pages at [vyenne.com](https://vyenne.com).

The editing source lives in `~/StoryBook`:

| Published file | Source file |
|---|---|
| `index.html` | `docs/interactive/website-final-0819.html` |
| `terms.html` | `docs/interactive/terms.html` |
| `privacy.html` | `docs/interactive/privacy.html` |
| `code-of-conduct.html` | `docs/interactive/code-of-conduct.html` |
| `assets/website/` | `docs/interactive/assets/website/` |

Make changes in StoryBook first, copy them here, then commit and push `main`. There is no build step.

The full source and publishing notes are in `~/StoryBook/docs/WEBSITE.md`.
